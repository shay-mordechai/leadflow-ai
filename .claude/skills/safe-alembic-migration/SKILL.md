# Safe Alembic Migration Guidelines (`leadflow-ai`)

1. **Explicit Constraint Names:** Always name foreign keys and indexes explicitly (e.g., `name="fk_knowledge_chunks_document_id"`).
2. **SQLite & Postgres Dual-Compatibility:** Avoid Postgres-only constructs in autogenerated migrations unless guarded or portable (e.g. `embedding_json` alongside `pgvector`).
3. **Migration Workflow:**
   - Remove any temporary local `.db`/`.sqlite` files.
   - Run `alembic upgrade head`.
   - Run `alembic revision --autogenerate -m "description"` to generate migration.
   - Run `alembic upgrade head && alembic check` to verify zero migration drift.
   - Clean up temporary `.db` files.
